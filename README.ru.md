# Horizon Prime

Современный клиент терминальной игры с поддержкой реал-тайм рендеринга через OpenGL и кастомного протокола.

**[Read in English](README.md)**

## Описание

Horizon Prime — это продвинутый терминальный клиент, который подключается к удалённому серверу для захватывающего игрового опыта. Клиент использует современные графические техники для обеспечения плавных анимаций и визуальных эффектов прямо в вашем терминале.

### Возможности

- **Реал-тайм рендеринг**: OpenGL для аппаратного ускорения графики
- **Кастомный протокол**: Эффективное бинарное взаимодействие с сервером
- **Текстовый интерфейс**: Продвинутый рендеринг текста с поддержкой шрифтов TrueType
- **Управление сценами**: Динамическая система сцен и анимаций
- **Кроссплатформность**: Написано на C++ для максимальной совместимости

## Сборка

### Требования

- C++17 или выше
- OpenGL 3.3+
- CMake 3.15+

\\\ash
git clone https://github.com/yourusername/horizon-prime-client.git
cd horizon-prime-client
mkdir build && cd build
cmake ..
make
\\\

## Запуск

\\\ash
./horizon-prime-client --server localhost:9000
\\\

## Архитектура

Клиент использует модульную архитектуру:

- **Renderer**: OpenGL-конвейер для графики
- **Protocol**: Кастомный бинарный формат для общения с сервером
- **Input**: Обработка ввода терминала
- **Scene Graph**: Иерархическое представление сцен
